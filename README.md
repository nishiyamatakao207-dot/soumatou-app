# めぐる — 声と写真の思い出ムービー（試作版）

旅行・イベント・子育ての瞬間を「写真・動画・その時の気持ち」と一緒に記録し、
あとから流れる映像（思い出ムービー）として見返すアプリの試作版です。

## 使い方（開発用）

```bash
npm install
npm run dev      # 開発用サーバー（同じWi-FiのスマホからもURLで開けます）
npm run build    # 公開用ファイルを dist/ に作成
npm run preview  # 作成したファイルで動作確認
```

> ホーム画面への追加（PWA）や音声入力は、**https のURLで開いたとき**だけ有効になります。
> スマホで試すときは dist/ を Netlify / Vercel / GitHub Pages などに置くのが手軽です。

## できること（第1版）

| 機能 | 内容 |
|---|---|
| 記録の作成 | 撮影・ライブラリから写真/動画を複数追加、並べ替え |
| 気持ち | 写真ごとにコメント（文字 または「🎙 声で入力」→ その場で文字に変換）。思い出全体のひとことも書ける |
| 日付 | 写真・動画1枚ごとに日付を持つ。写真の撮影日（EXIF）・動画の撮影日 → ファイルの日付 → 記録の日付 の順に自動で入れ、1枚ずつ手で直せる。一覧・再生は1枚ごとの日付順 |
| タグ | 複数付けられる。自由に追加でき、よく使うタグが候補に出る |
| 一覧 | 月ごとに区切ったタイムライン（新しい順） |
| 絞り込み | タグ（複数可）×期間（今年／去年／最近30日／期間指定） |
| 思い出ムービー再生 | 絞り込んだ思い出を古い順に再生。丸く切り抜いてふちをぼかした写真が、画面のあちこちにふわっと現れては消え（前後の写真は重ねて切り替え）、表示中はゆっくり漂う。コメントは写真の下についていく。背景は写真の色合いから作り、写真が変わると色が移り変わる |
| 動画にする | 再生前の画面の「🎬 動画にして共有」から、絞り込んだ内容を今の見た目のまま MP4（縦長720×1280）に書き出し、共有メニュー（LINEなど）や端末への保存ができる。進み具合と残り時間を表示 |
| BGM | 再生と動画の書き出しにBGM。「やさしい」「明るい」「しっとり」はアプリ内で作曲・演奏する音楽（第三者の音源を使わない）。「自分の曲」でスマホの音楽ファイルも使える。動画の音がある間はBGMを小さくする |
| 今日のひとめぐり | アプリを開いたとき（または1時間以上たって戻ってきたとき）、過去の写真からランダムに8枚・約1分の走馬灯を自動で流す。スキップ・「次から表示しない」・設定でオン／オフ |
| 記録のハードル | 一言でOK・ひとことの候補、写真だけで保存して「気持ちを足す」、一覧の「声で残す」で押した瞬間に録音、前回のタグを最初から選択 |
| 季節の雰囲気 | 再生と書き出しで、写真を撮った季節の粒（春：桜の花びら、夏：ほたる、秋：紅葉、冬：雪）と季節の色を背景に重ねる |
| 思い出の星空 | トップ画面の星空に記録1つにつき星が1つ（左が古い・右が新しい、同じ年は星座の線）。タップで記録が開き、新しい星は流れ星になって灯る。空は今日の季節の雰囲気 |
| ◯年前の今日 | 去年以前の同じ月日の記録があれば、その日はじめて開いたときにお知らせ（ひとめぐりより優先）。タップでその日の走馬灯（日付の横に「◯年前」）。一覧の上にカード、設定でオン／オフ |
| 未来への手紙 | 記録に「開けられる日」と宛名を設定して封をすると、その日まで中身を誰も見られない（一覧は封筒だけ、再生・ひとめぐり等にも出ない、星空では光るのを待つ星）。日付が来たら開いたときにお知らせし、封筒を開ける演出のあと普通の記録になる。※端末内の約束で強い鍵ではない。長期保存にはバックアップが必要 |
| 再生中の操作 | 画面中央タップ＝一時停止、左右の端＝前/次、🔊消音切替 |

## 設計

```
src/
  data/          … データの形と保存（ここだけ差し替えれば保存先を変えられる）
    types.ts       Memory（記録）/ MediaItem（写真・動画）
    db.ts          端末内データベース（IndexedDB）
    repository.ts  画面から使う窓口（一覧・保存・削除・タグ集計）
  lib/           … 画面に依存しない道具
    media.ts       写真の縮小・撮影日読み取り・動画のサムネイル
    speech.ts      音声入力（ブラウザ内蔵の音声認識）
    filter.ts      タグ/期間の絞り込み条件
  screens/       … 画面（一覧 / 記録 / 再生）
  components/    … 部品（サムネイル、タグ選択、絞り込みバー）
```

### データの持ち方
- **Memory（記録）**: 日付・気持ちの文章・タグ・メディアの並び順
- **MediaItem（写真・動画）**: ファイル本体と小さいサムネイル。大きいので記録とは分けて保存
- 写真は長辺2048pxに縮小して保存（容量の節約）。動画はそのまま（200MBまで）

### 使っている技術とその理由
| 技術 | 役割 | 理由 |
|---|---|---|
| React + TypeScript | 画面づくり | 情報が多く、将来 React Native 等への移行もしやすい |
| Vite | 開発・ビルド | 速く、設定が少ない |
| vite-plugin-pwa | ホーム画面追加・オフライン動作 | 設定だけでPWA化できる |
| IndexedDB（Dexie） | 端末内保存 | 写真・動画のような大きなデータをブラウザ内に保存できる唯一の現実的な方法 |
| Web Speech API | 声の文字起こし | ブラウザ内蔵で無料。iPhone Safari / Android Chrome 対応 |
| exifr（軽量版） | 写真の撮影日読み取り | |

### ネイティブアプリ化の道すじ
1. **Capacitor** でこのWebアプリをそのまま包み、App Store / Google Play 用アプリにする（一番の近道）
2. 保存先を `repository.ts` の中だけ差し替え（端末のファイル保存、またはクラウド同期）
3. 音声認識はネイティブの音声認識プラグインに差し替え（`speech.ts` だけ）

## 試作版の注意点
- データはその端末のブラウザの中だけにあります。**ブラウザのデータ消去やアプリ削除で消えます**（バックアップ機能は次の改良候補）
- iPhone の Safari では、しばらく使わないとブラウザがデータを消すことがあります。ホーム画面に追加して使うと消えにくくなります
- 音声入力は端末/ブラウザによって使えない場合があります（その場合はキーボードのマイクボタンで代用できます）

## 次の改良候補
- バックアップ（書き出し・読み込み）
- 再生速度の調整
- 声そのもの（音声ファイル）も残す
- 人物・場所での絞り込み

## BGM の出典とライセンス
- 「やさしい」「明るい」「しっとり」の3曲は、このアプリのコード（`src/lib/music.ts`）が端末の中で作曲・演奏する音楽です。
  録音された音源・サンプル音・他の人の楽曲は使っていないため、第三者の著作権・ライセンスの制約はありません（商用利用可）。
- 「自分の曲」で選んだ音楽ファイルの権利は、その曲の権利者にあります。市販の曲を入れた動画を広く公開・配布しないでください。
